Wire-compatible with 0.34.x except where Before you update says otherwise. On Windows, the host and the display driver must update together.

- **Matching Windows host and driver.** They ship in one installer. A mix from different releases will not stream.
- **No bundled FFmpeg.** The host encodes with your GPU's own encoder.
- **Linux install is a download, then a setup program.** The one-liner still works.
- **A browser can stream.** Off until you turn it on.
- **Clipboard sharing starts off on Android.** Turn it on per host if you want it.
- **No game-library switch on Apple or Android.** Pairing is the gate.
- **Foldable phone.** Picture on the upright half, on-screen controller on the flat one.
- **Launch hold.** The game's cover stays until the title is up.

## Before you update

- **Windows: run the installer.** It updates the host and the display driver together. Expect a brief black screen while the driver reloads. Do not keep a 0.34 driver under a 0.35 host.
- **Apple and Android: the game-library switch is gone.** Pairing decides whether you see games. A stored off setting is ignored.
- **A browser stream stays off.** Nothing changes unless you enable it.
- **Clipboard sharing starts off on Android.** Turn it on per host if you want it.

## New

- **Quick-action ring on a Mac.** Stream menu, Ctrl+Alt+Shift+O, or Select+A.
- **On-screen controller layout.** Drag each stick and button. A foldable phone splits at the hinge.
- **Launch hold.** Cover until the game is up. Bind a settings profile to one title. Resume a game the host already has running.
- **Steam Deck: stream from Steam's Play menu.**
- **Omarchy.** Bar widget, live theme, saved hosts in Super+Space.
- **More stores in the library.** Ubisoft Connect, Amazon Games, Battle.net, Flatpak, Bottles, itch.io.
- **Steam Controller 2 on a Mac over USB or a Puck dongle.**
- **Network speed test** in the gamepad console.

## Improved

- **A glitch in the picture heals without a full refresh.**
- **Linux desktops keep the refresh rate they run at.** Hyprland, GNOME and KDE.
- **Trackpad scrolling matches your fingers.**
- **A sleeping host shows Offline, and auto-wake fires.**
- **Installers.** Linux downloads a setup program. Windows is Punktfunk's own wizard. SteamOS is in the guided path.
- **The overlay is larger on a TV.**

## Fixed

- **Android: Select+A opens the ring on any pad.** A 10-bit colour reset now sticks.
- **iPad: audio no longer lags the picture.** The mic path no longer drops out every half minute.
- **A Mac with no microphone connects instead of crashing.**
- **Two controllers no longer swap rumble.** DualSense adaptive triggers fire in game.
- **Forgetting one unpaired host no longer forgets them all.**
- **A host-side setup failure says so on iPhone and Android.**

## Security

- **Clipboard sharing starts off on Android.** Turn it on per host if you want it.
- **A fake advert on the LAN can no longer replace a host's wake address.**
