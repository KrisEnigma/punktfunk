Wire-compatible with 0.35.x: a new client streams from an old host and the other way round, so you can update one side at a time. On Windows the installer still updates the host and its display driver together.

- **Let a friend in from the internet, safely.** A device knocking from outside your network is marked, can't be approved by its name, and gets in only with a PIN you arm for that one device. "Until they disconnect" ends its access with its session.
- **Android keeps a stream running in the background**, behind a notification. Off until you turn it on.
- **L3 and R3 on the on-screen controller**, on Android, iPhone and iPad.
- **Mac: the stream matches your panel**, and a notched Mac fills the whole screen or sits just below the notch. A lost packet no longer freezes the picture for a full refresh.
- **Android handhelds pace frames evenly.** Two frames no longer land in one refresh and cost a drop.
- **Steam Controller 2 on Android TV.** The USB permission sticks, the pad drives the menus without capture, and a TV remote drives the quick-action ring.
- **Hyprland and Omarchy keep your screen across a reconnect**, windows included, and the Omarchy bar has a new panel.
- **Gamescope hosts stream to Linux clients again**, and a SteamOS desktop with an NVIDIA card streams.

## Before you update

- **Windows 10 can't run the host.** The installer now refuses a host install below Windows 11 22H2 before it changes anything; the virtual display never started there. The client still installs on Windows 10.

## New

### Pairing and guests

- **Knocks from the internet are marked.** The console tags a pending device that knocked from outside your network "From the internet" and offers no Approve for it. **Arm PIN** opens a PIN for that one device; a PIN you armed for your own next device never admits it. Devices on your network and on Tailscale pair as before.
- **"Until they disconnect."** A new expiry for a paired device: a minute after its last session ends, its record is removed, so nothing is left to clean up. It is the default for a PIN armed for a device from the internet.
- **The Connect card's link works on a new device.** It now carries the host's address and fingerprint, so a friend's first connect is verified instead of blind.
- **The [Friends over the internet](https://docs.punktfunk.unom.io/docs/friends-over-the-internet) guide** covers port forwarding as the last resort, with the rules above.

### Android

- **Keep streaming in the background.** Turn it on in settings and a glance at another app no longer ends the stream: the sound keeps playing, and the notification's End button stops it. Not on Android TV.
- **Steam Controller 2.** A wired SC2, a Puck or a DualSense keeps its USB permission across plugs, including on Android TV where the prompt often never appeared. An uncaptured SC2 drives the menus as a pad and names itself on the controller chip.
- **A hovering mouse moves the console's cursor.** A TV remote, arrow keys and Escape drive the quick-action ring.
- **A keyboard on a combined receiver types in the console**, and its Y and X keys open a tile's options.

### Mac

- **"This display" is your panel's real size.** A scaled Mac used to stream the larger picture the system shrinks: 3420×2224 on a 2560×1664 MacBook Air.
- **Notched Macs.** Full screen fills the panel, camera housing included, and a new "This display (below the notch)" mode sits flush under it.

### Hyprland and Omarchy

- **Keep-alive on Hyprland.** A disconnect leaves the streamed screen up for the keep-alive window, and reconnecting returns to it instead of an empty one. When it does come down, its windows move to a physical monitor instead of disappearing.
- **A new Omarchy bar panel** with Session, Pairing, Devices and Display sections. Super+Space gains rows for Dedicated display or This screen, a Moonlight PIN, Unpair and GameStream.
- **Tailscale reaches an Omarchy host that joins a tailnet later.** Setup installs the firewall rule before the interface exists.

### Everywhere

- **The host names the screen it couldn't find.** A host set to stream a monitor it no longer has fails the session at once with that monitor's name, instead of a black screen for 15 seconds and a generic error. The console marks the missing screen.
- **Linux and Windows clients say when a pinned bitrate is too much for the device**, instead of stuttering silently.
- **Choose the console password during setup on Linux.** Keep the generated one, with the command that prints it, or type your own. On Windows, `punktfunk-host web password` in an elevated PowerShell prints it after a silent or winget install.
- **The console's sign-in says when a locked-out attempt can retry.**

## Improved

- **Recovery no longer feeds the overload it repairs.** A client that can't decode the stream no longer gets a full keyframe on a fixed beat; each one that does not heal doubles the wait, up to 3 s. Loss protection follows what the network loses, not frames a slow client dropped, so the host stops spending bandwidth on parity it can't use.
- **Logs tell a network drop from a stalled client.** The host logs what left its network card, and the client logs how long nothing arrived versus how long it stopped reading.
- **The console's Logs tab shows host events** instead of a wall of TLS handshakes.
- **PyroWave on Android TV.** A device that can't decode it says "unsupported" and names the requirement, instead of offering a choice that did nothing.

## Fixed

- **Mac:** a single lost packet no longer freezes the picture about 300 ms for a full keyframe; the repair frame heals it.
- **Windows clients on AMD graphics, such as the ROG Ally:** after a lost frame, HEVC no longer decodes smeared until the next keyframe.
- **Linux and Windows clients:** V-sync on no longer tears on a display that offers only immediate and FIFO presentation.
- **Dual-boot hosts:** both OS installs of one box stay two hosts. Pairing one no longer retires the other, forgetting by address refuses to remove both, and the online dot checks which one answered. A machine that took a sleeping host's address no longer reads as that host, so Wake-on-LAN fires.
- **Android:** a paired host stays reachable after the TV moves between Wi-Fi and Ethernet, without restarting the app.
- **Linux host:** Steam, Lutris and other X11 apps launched from the library open instead of failing "Unable to open a connection to X". A KDE host above 60 Hz keeps the refresh rate you asked for when KDE remembered an old layout. Super no longer sticks on Hyprland after a client loses a key release. The plugin runner can be switched back on after it was switched off, and an Ubuntu install no longer refuses every plugin.
- **Gamescope hosts:** Linux clients get a picture again, HDR included. On NixOS a nested session finds Steam and its reaper.
- **SteamOS host:** a desktop with an NVIDIA card streams. A host built without an encoder no longer blanks a KDE desk eight times before giving up. A source build's update card reports the commit it built and offers an update only when there is one.
- **Setup:** Bazzite no longer waits forever on "Controller access".
- **Omarchy:** the menu's checked capture row follows a `PUNKTFUNK_CAPTURE_MONITOR` override.
- **Windows host:** a hung display driver no longer hangs every session while the host reports busy; the host reloads it. One tray icon per signed-in user again. Uninstalling the client removes its Start menu and desktop shortcuts.
- **Web console:** Firefox's saved password signs in, and a signed-in visit to the sign-in page goes on to where you were headed. Game-source settings open for a plugin that keeps them on its own page, a running source shows as running, and a refusal says why.

## Security

- **A device from the internet can't be admitted by its name.** The host itself refuses Approve for it; only a PIN armed for that device works.
- **The host checks that a first packet's sender can answer** before it spends a handshake on it, so a spoofed flood can't make it amplify.
- **The web console's dependencies moved past two Next.js remote code execution advisories** and two others.
- **A crafted sign-in link can no longer loop the console**, and the redirect check behind it now has a test.
- **A configured gamescope layer path is quoted**, so shell syntax in it can't run.
